# 胆固醇全解 · 十课教学报告

一份从零讲透 **胆固醇 / LDL（低密度）/ HDL（高密度）/ 甘油三酯** 的交互式 HTML 教程，
专为「测出 LDL 偏高、想彻底搞懂并知道怎么应对」的人准备。

## 它涵盖什么

- **是什么**：胆固醇、LDL、HDL、甘油三酯、残余胆固醇、Lp(a) 的本质与区别
- **怎么运转**：身体如何**生产**（肝脏合成 / 他汀作用点）、**利用**（LDL 受体 / 激素 / 维生素 D）、**排泄**（胆汁 / 肠肝循环 / 逆向转运）
- **有何影响**：动脉粥样硬化从一个 LDL 颗粒到心梗的六阶段全过程
- **因果证据**：用三类独立证据（基因 / 随机试验 / 剂量—时间）说明为什么 LDL 是「元凶」
- **你的情况**：影响 LDL 的因素**按影响力排序** + 每一项的具体对策
- **行动与监测**：分层目标值、12 周计划、**多久复查一次**的时间表、何时该用药

全程穿插 **20+ 张信息图**，并整合了 **12 篇最有影响力的研究/指南**的结论
（EAS 共识、CTT 他汀荟萃、Ference 终身暴露、Nordestgaard 残余胆固醇、PREDIMED、
2019 ESC/EAS 指南、Portfolio Diet、燕麦/植物固醇荟萃等）。

## 怎么用

1. 直接用浏览器打开 `index.html` 即可阅读（纯本地、无需联网、无外部依赖）。
2. 想要 **~30 页的 PDF 报告**：在浏览器里按 `Ctrl/Cmd + P` → 目标选「另存为 PDF」→
   纸张选 A4 → 勾选「背景图形」→ 保存。文件内置了打印分页样式。

## 重要声明

本教程为**健康科普与教育用途**，帮助你理解概念、读懂化验单、与医生高效沟通，
**不能替代医生的诊断与个体化处方**。文中的目标值与研究数据来自公开发表的指南与论文，
但你的具体方案必须由了解你完整病史的医生决定。
